# Sales Performance Dashboard | Power BI

## Project Overview

An interactive Business Intelligence dashboard developed using Microsoft Power BI to analyze retail sales performance, revenue, profitability, transactions, and product returns.

The project analyzes 269,720 transaction records and 833,489 units sold across 1,560 unique products to provide insights into business performance.

## Key Features

- Revenue, profit, and transaction KPI tracking.
- Product, store, and country-level sales analysis.
- Weekly sales performance and trend analysis.
- Product return rate monitoring.
- Interactive maps, treemaps, KPI cards, and slicers.
- Dynamic reporting and drill-down analysis.

## DAX Measures

Developed 14 DAX measures, including:

- Total Revenue
- Total Cost
- Total Profit
- Profit Margin
- Total Transactions
- Quantity Sold
- Quantity Returned
- Return Rate
- Weekend Transactions
- % Weekend Transactions
- Unique Products

## Tools & Technologies

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Data Visualization
- Business Intelligence
- KPI Reporting

## Business Analysis Scope

The dashboard focuses on evaluating revenue performance, profitability, product sales, geographical performance, and customer return patterns to support data-driven business decisions.
